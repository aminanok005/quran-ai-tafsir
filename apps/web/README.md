# QURAN AI web

Thai-first Quran reader and tafsir study workspace built with Next.js 14.

## Run locally

From the repository root:

```sh
bun install
bun run dev:web
```

The current interface is an interactive UI preview. Arabic text is marked as
sample content, Thai translation is intentionally withheld until a verified
source is connected, and the preview is not yet connected to the API. Tafsir
questions therefore do not generate answers or citations.
