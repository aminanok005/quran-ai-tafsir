# Quran AI Skills Directory

This directory stores project-specific superpowers skills.

Skills are invoked via the `skills` tool with format: `skill: "<skill-name>"`

Available project skills:
- `test-driven-development`: Run pytest suites
- `executing-plans`: Plan and execute implementation tasks
- `writing-plans`: Create detailed implementation plans
- `subagent-driven-development`: Use subagents for task execution
- `verification-before-completion`: Verify fixes before reporting success
- `writing-skills`: Create new skills following best practices

Common skill commands:
- `skill: "find-skills"` - Discover available skills
- `skill: "executing-plans"` - Execute a plan inline
- `skill: "writing-plans"` - Create detailed implementation plans
- `skill: "test-driven-development"` - Run test suites

This directory is git-ignored and project-local.
